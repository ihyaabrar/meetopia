# Illustrated Meetopia maps

Generated with the built-in imagegen tool on 6 October 2026. User-provided map mockups are style references; code-native maps rendered by `scripts/render-map-guides.mjs` are geometry guides. These are environment artwork only, not UI screenshots. Labels, avatars, media controls and gameplay remain live.

Runtime files are WebP (quality 88, about 10x smaller than the generated PNGs). Final assets: `office-v2.webp`, `home-v1.webp`, `gaming-v1.webp`, `studio-v1.webp`, `rooftop-v1.webp`. The initial `office-v1` draft is kept outside the repository; runtime consumes v2.
