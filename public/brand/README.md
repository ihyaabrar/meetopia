# Meetopia visual identity

Logo konsep 7 (dua daun pintu) tetap menjadi identitas utama. Semua varian menggunakan geometri yang sama dengan komponen LogoMark; bukan logo baru yang mengganti pilihan pemilik.

- mark-dark.svg: mint + paper, untuk latar ink-teal.
- mark-light.svg: mint + ink, untuk latar terang.
- mark-mono.svg: satu warna melalui currentColor, untuk cetak sederhana.
- board.svg: lembar panduan visual dengan contoh pemakaian dan palet.
- Favicon aplikasi berada di src/app/icon.svg dan memakai varian gelap.

Ukuran minimum mark: 20px; jangan kompres proporsi. Clear space minimal seperempat lebar mark. Hindari shadow/glow/bevel. Wordmark aplikasi tetap Outfit dengan font fallback system-ui; teks pada board SVG masih editable, bukan outline font.

Palet: mint #00cf92, ink #09151c, panel #11232b, paper #f2f7f5. Mint menandai tindakan dan pilihan aktif, bukan setiap dekorasi. Isi dunia memakai warna material hangat yang berbeda per map.
